# Northern Bay of Bengal Oceanographic Analysis (2006–2025)

A lightweight Python workflow for downloading, processing, and visualising spatio-temporal trends in **Sea Surface Temperature (SST)** and **Chlorophyll-a (CHL)** concentrations across the Northern Bay of Bengal and ENSO influence.

---

## 📌 Features

* **Data Ingestion**: Subset and fetch CMEMS reanalysis & satellite data via `copernicusmarine`.
* **Spatial Mapping**: Seasonal and monthly spatial distribution maps using `Cartopy` and `cmocean`.
* **Area-Weighted Means**: Cosine-latitude weighting for accurate physical spatial aggregations.
* **Time-Series Analysis**: Dual-axis line plots and climatology profiles comparing SST vs. CHL.
